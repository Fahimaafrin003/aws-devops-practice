# Terraform Practice

## What is Terraform?
Terraform is an Infrastructure as Code (IaC) tool used to create and manage cloud infrastructure using configuration files.

## Infrastructure as Code (IaC)
- IaC allows us to manage infrastructure using code instead of manual configuration.
- It helps in automation, consistency and easy management.

## Terraform Workflow

### 1. Write
- Create Terraform configuration files (.tf).

### 2. Init
```bash
terraform init
terraform plan
terraform apply
